# Čizmići

Neslužbena digitalna lična karta mjesne zajednice Čizmići (Grad Cazin). Nije zvanična stranica MZ ni Grada.

## Pokretanje

```bash
npm install
npx next dev --port 3005
```

Otvori [http://localhost:3005](http://localhost:3005).

Ako je port 3000 zauzet (npr. Grafana), ostavi 3005.

## Stanje projekta

Šta je gotovo, šta ne gradimo i šta je sljedeće: [`STANJE.md`](STANJE.md). Taj fajl se ažurira uz svaku stvarnu izmjenu da se kontekst prenese na drugi računar.

## Stack

Next.js 15, React 19, sadržaj u `content/*.json`.
